# BizConnect Chatswood

**The Pitch:** A multi-cultural connectivity platform that bridges the gap between Chatswood Council and local businesses via a geospatial "single source of truth."

## Core Features
- **Spatial Mapping:** Select map polygons to send targeted alerts (e.g., roadworks) to specific businesses.
- **Cultural Sync:** AI extraction of multi-lingual business data (names, services, hours) with translations.
- **WhatsApp Interface:** Bot-driven management of business profiles, service lists, and reporting.
- **Data Heartbeat:** Mandatory 6-month verification cycle linked to lease/council triggers.

## Tech Stack
- **Web:** React + Mapbox (Council Dashboard).
- **Mobile:** WhatsApp API (Primary user interface).
- **Backend:** Node.js + PostGIS (Geospatial intelligence).
- **Intelligence:** LLM Scrapers (Multi-lingual data extraction).
